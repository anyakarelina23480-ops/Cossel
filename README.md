# Cossel
Индивидуальная подборка косметических средств.

## О проекте
Сайт предназначен для помощи пользователям в выборе декоративных косметических средств с учетом индивидуальных особенностей и предпо-чтений. Пользователь сможет указать тип кожи, категорию товара, непере-носимости некоторых компонентов и другие параметры, после чего систе-ма предложит наиболее подходящие косметические средства.

## Технологии

- HTML
- CSS
- JavaScript

## Как запустить
Открыть файл index.html в браузере.

## Реализованные возможности
- Просмотр каталога косметических средств
- Поиск по названию и бренду
- Фильтрация по категории
- Просмотр карточки товара
- Анкета подбора из 3 шагов
- Добавление/удаление товаров в избранное
- Отдельная страница «Избранное» с сохранением через localstorage
