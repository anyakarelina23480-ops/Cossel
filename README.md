# Cossel (Cosmetics Selection)
Индивидуальная подборка косметических средств.

## О проекте
Сайт предназначен для помощи пользователям в выборе декоративных косметических средств с учетом индивидуальных особенностей и предпочтений. Пользователь сможет указать тип кожи, категорию товара, непереносимости некоторых компонентов и другие параметры, после чего система предложит наиболее подходящие косметические средства.

## Технологии

- HTML
- CSS
- JavaScript

## Как запустить
Открыть файл index.html в браузере или открыть через репозиторий GitHub (через GitHub Pages сайт можно открыть по ссылке на опубликованную страницу.)


## Реализованные возможности
- Просмотр каталога косметических средств
- Поиск по названию и бренду
- Фильтрация по категории
- Просмотр карточки товара
- Анкета подбора из 3 шагов
- Добавление/удаление товаров в избранное
- Отдельная страница «Избранное» с сохранением через localstorage
